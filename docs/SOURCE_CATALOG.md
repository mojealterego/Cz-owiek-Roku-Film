## 5. SOURCE PRIORITY

When sources appear to conflict:

1. SCREENPLAY — event/action/dialogue/structure.
2. BOOK — inner voice, psychology, sensory and supplementary material.
3. PODCAST — narrative mechanism and authorial construction.
4. OPEN LETTER — social purpose.
5. RAPORT Z PIEKŁA — visual language.
6. USER VISUAL REFERENCES — character continuity only unless explicitly assigned a narrative fact.
7. EXTERNAL WEB / VIDEO REFERENCES — research/reference layer; never silently promoted to canon.

## 6. SOURCE LOCK PROTOCOL

Every new production element must be tagged internally as one of:

- SOURCE
- ADAPTATION
- FILM DECISION
- REFERENCE LOCK
- CONTINUITY LOCK
- UNVERIFIED REFERENCE

No unverified external material is to be presented as screenplay fact.
