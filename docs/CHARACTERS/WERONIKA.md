# WERONIKA — CHARACTER / VISUAL REFERENCE

## 1. SOURCE IDENTITY

- Imię: Weronika.
- Żona/partnerka Andrzeja w historii.
- Jej relacja z Andrzejem jest centralnym źródłem rozpadu jego dotychczasowego życia.
- Jej portret stanowi pierwotny tatuaż na plecach Andrzeja; później tatuaż zostaje przekształcony.

## 2. VISUAL REFERENCE LOCK

Użytkownik dostarczył zdjęcia referencyjne przedstawiające Weronikę razem z Zuzią. Zdjęcia stanowią podstawową referencję wizualną Weroniki dla produkcji filmu.

Widoczne cechy referencyjne:
- dorosła kobieta;
- długie, jasne/blond włosy;
- włosy o dużej objętości, naturalnie opadające wokół twarzy;
- jasna karnacja;
- jasne oczy;
- proporcjonalna, smukła twarz;
- naturalna faktura skóry;
- naturalny wygląd bez potrzeby beauty-retuszu;
- kobieca, naturalna sylwetka.

## 3. REFERENCE PHOTO CONTEXT

Zdjęcia pokazują Weronikę i Zuzię razem w domowym, świątecznym otoczeniu przy choince. Świąteczna garderoba i aranżacja są kontekstem fotografii referencyjnej, a nie automatycznym lockiem garderoby/scenografii wszystkich scen filmu.

## 4. CONTINUITY RULE

W kolejnych ujęciach Weroniki należy utrzymywać:
- spójność twarzy;
- spójność wieku i sylwetki wynikającą z chronologii;
- zgodność fryzury z daną sceną/okresem;
- naturalną fakturę skóry;
- brak przypadkowych zmian wyglądu pomiędzy ujęciami.

## 5. ANDRZEJ TATTOO REFERENCE — CRITICAL LINK

Weronika ma bezpośrednie znaczenie dla ciągłości tatuażu Andrzeja.

### EARLY / PRE-TRANSFORMATION
Na plecach Andrzeja znajduje się **portret Weroniki**.

### TRANSFORMATION
W trakcie historii Andrzej tatuuje/przekształca ten portret.

### LATE / POST-TRANSFORMATION
Dopiero po transformacji dawny portret Weroniki zostaje przekształcony w dużą kobiecą kompozycję inspirowaną Santa Muerte.

Nie wolno pokazywać późniejszej wersji Santa Muerte przed momentem transformacji.

## 6. DO NOT INVENT

Nie dopisywać na podstawie zdjęć:
- prawdziwej tożsamości osoby;
- biografii;
- psychologii niewynikającej ze źródeł;
- motywacji niewynikających ze scenariusza/książki;
- zawodu lub dodatkowych faktów;
- stałej garderoby poza wymaganiami sceny;
- nowych cech fizycznych bez źródłowego uzasadnienia.

Zdjęcia są referencją wizualną, nie samodzielnym źródłem fabuły.
