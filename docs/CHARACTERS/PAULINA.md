# PAULINA — CHARACTER / VISUAL REFERENCE

## 1. STATUS

Paulina jest postacią drugoplanową, która pojawia się tylko w jednym miejscu historii.

**Ustalenie użytkownika:** Paulina pojawia się w **59. rozdziale**, **w lodziarni**.

To jest obecnie jedyny twardy lock dotyczący jej miejsca w narracji.

## 2. VISUAL REFERENCE

Użytkownik dostarczył zdjęcia referencyjne Pauliny. Mają służyć wyłącznie do zachowania ciągłości wizualnej postaci w ujęciu filmowym.

Widoczne cechy referencyjne:
- młoda dorosła kobieta;
- szczupła twarz;
- wyraźne kości policzkowe;
- jasne niebiesko/szare oczy;
- ciemne, wyraźnie zarysowane brwi;
- długie rzęsy;
- pełne usta;
- prosty, proporcjonalny nos;
- bardzo długie, ciemne/czarne włosy;
- włosy proste lub lekko falujące, objętościowe;
- przedziałek w okolicy środka;
- szczupła, naturalna sylwetka;
- widoczny tatuaż na górnej części ramienia;
- mały/delikatny tatuaż w okolicy obojczyka/górnej części klatki piersiowej.

W scenie Pauliny należy zachować jej wygląd zgodnie z dostarczonymi zdjęciami.

Nie wolno na podstawie zdjęć dopisywać:

- biografii;
- osobowości;
- zawodu;
- relacji z innymi postaciami;
- znaczenia tatuaży;

Te elementy muszą pochodzić ze scenariusza/książki albo być jawnie oznaczoną decyzją filmową.
