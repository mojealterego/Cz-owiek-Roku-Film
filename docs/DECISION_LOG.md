# DECISION LOG

## Initial repository capture

### D-001 — Repository as project memory
The repository is the persistent project memory. Important established decisions must be written to GitHub, not left only in chat.

### D-002 — Source hierarchy
Screenplay controls action/dialogue/structure; book controls psychological/internal material and additional texture; podcast controls narrative mechanisms and authorial construction; open letter controls social purpose; „Raport z piekła” informs visual language; final film is an original synthesis.
