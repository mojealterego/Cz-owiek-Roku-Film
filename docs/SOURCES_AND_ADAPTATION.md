# SOURCES & ADAPTATION MATRIX

## Source hierarchy

| Source | Primary function |
|---|---|
| SCENARIUSZ | akcja, dialog, struktura, sceny, screen time |
| KSIĄŻKA | monolog wewnętrzny, psychologia, pamięć, sensoryka, dodatkowa faktura |
| PODCAST | mechanizmy narracyjne, głos autora, konstrukcja angażowania odbiorcy |
| LIST OTWARTY | cel, wymiar społeczny, manifest, intencja |
| RAPORT Z PIEKŁA | kierunek języka filmowego i estetyki |
| FILM | autonomiczna synteza wszystkich powyższych źródeł |

## Adaptation rule

Każdy ważny element przechodzi przez:

`[SOURCE] → [SCREENPLAY] → [ADAPTATION DECISION] → [FILM DECISION]`

Nie wolno udawać, że decyzja filmowa jest faktem źródłowym.

## Book-derived motifs already selected for cinematic translation

### Photography / lies
Otwarcie i późniejszy język obrazu mogą wykorzystywać fotografię jako metaforę łapania kłamstw.

### Theatre / artificial prestige
- burgundowa kurtyna;
- sztuczne złote światło;
- kurz;
- lakier;
- perfumy;
- lokalne elity;
- garnitury;
- alkohol;
- scena i odbicia.

### Łęczna / journey
- mieszkanie;
- 26 tys. długu;
- podróż ok. 500 km;
- zatłoczony brudny pociąg;
- pot i zapach;
- zaparowane/brudne szyby;
- rytm kół przypominający bicie serca.

### Bureaucratic wall
- „mur biurokracji”;
- redukcja relacji i miłości do numeru sprawy;
- cicha forma przemocy;
- cicha epidemia ojców wypychanych w cień.

### Diary / black box
- nocne pisanie;
- zimny pokój;
- niebieskie światło monitora;
- pamiętnik jako czarna skrzynka.

### Award / emptiness
Prestiżowa nagroda fotograficzna ma kontrastować z emocjonalną pustką bohatera.

### Zuzia / photograph
Zuzia ukrywa zmięte zdjęcie, a zachowanie dziecka zostaje przedstawione jako napięcie pomiędzy pamięcią, miłością, lojalnością i lękiem.

## Podcast-derived narrative mechanics

- książka jako „maszyna” utrzymująca uwagę;
- zmodyfikowane cytaty jako haczyki narracyjne;
- brutalny język zmniejszający dystans;
- upadek „Człowieka Roku”;
- trzy warstwy konfliktu: osobista, systemowa, społeczna;
- system jako Goliat przechodzący w konkretne twarze/nazwiska;
- elementy thrillera/ekspozycji;
- przemiana ofiary w aktywistę;
- pisanie jako działanie publiczne;
- pojawienie się innych ojców;
- „Strajk Ojców Online” jako symbol ruchu.

## Important limitation

Podcast jest źródłem opisu konstrukcji i intencji narracyjnej, a nie samodzielnym dowodem faktograficznym wydarzeń.
